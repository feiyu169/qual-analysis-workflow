# Qual Workflow v8: Gate-Driven Investment Analysis

## 概述

2026-08-08实现的完整Gate-Driven投资分析工作流，基于HeavySkill K=8五轮迭代审查（v8.0→v8.4）。

## 9个Gate

| Gate | 名称 | 核心检查 | 确定性规则 |
|------|------|----------|----------|
| 0 | 数据源验证 | 财报+Wind | 文件存在、覆盖率≥95%、数值类型正确 |
| 1 | 类型推断+数据提取 | 市场类型、事实 | 市场类型有效、必填字段、偏差≤2% |
| 2 | 参数提取 | DCF参数 | \|FCF\|>0.01、WACC 5-15%、TG 1-5% |
| 3 | 逐章写作 | 11章 | 每章≥500字、无Placeholder、数据一致 |
| 4 | 审计修复 | 逻辑矛盾 | 格式错误=0、矛盾≤2、风险≥8类 |
| 5 | 质量增强 | 估值 | DCF±50%股价、组件100%集成 |
| 6 | 综合结论 | 决策章 | ≥1000字、评级与估值一致 |
| 7 | 问题转化 | 记忆 | 转化成功率≥90%、Schema通过 |
| 8 | 最终验证 | 人工确认 | 所有Gate通过、人工确认 |

## 关键设计决策

1. **第三方监督**: 规则驱动（秒级），不使用HeavySkill
2. **数据源不可用**: 5条件严苛判定+人工同意
3. **异常处理**: 临时/永久/业务三类+熔断器+指数退避
4. **审计日志**: 哈希链+外部锚定+只追加
