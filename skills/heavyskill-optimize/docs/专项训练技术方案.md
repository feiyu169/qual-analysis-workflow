### 2.2 核心组件

#### 组件 1：领域识别器

**功能**：自动识别待审查方案的领域，选择对应的检查清单。

```python
class DomainClassifier:
    """领域识别器"""
    
    DOMAIN_KEYWORDS = {
        "security": ["认证", "授权", "密码", "token", "jwt", "session", "登录", "权限"],
        "architecture": ["微服务", "服务", "架构", "模块", "组件", "依赖", "通信"],
        "performance": ["并发", "性能", "缓存", "队列", "异步", "负载", "优化"],
        "database": ["数据库", "表", "索引", "查询", "SQL", "事务", "备份"],
        "api": ["API", "接口", "REST", "请求", "响应", "版本", "分页"],
        "deployment": ["部署", "容器", "Docker", "Kubernetes", "K8s", "CI/CD"]
    }
    
    def classify(self, content: str) -> List[str]:
        """识别领域"""
        domains = []
        content_lower = content.lower()
        
        for domain, keywords in self.DOMAIN_KEYWORDS.items():
            if any(kw in content_lower for kw in keywords):
                domains.append(domain)
        
        return domains if domains else ["general"]
```

    def get_checklist(self, domains: List[str]) -> Dict:
        """获取检查清单"""
        checklist = {"name": "综合审查清单", "items": []}
        
        for domain in domains:
            if domain in self.CHECKLISTS:
                checklist["items"].extend(self.CHECKLISTS[domain]["items"])
        
        return checklist
    
    def format_checklist(self, checklist: Dict) -> str:
        """格式化检查清单为文本"""
        lines = [f"# {checklist['name']}\n"]
        
        for item in checklist["items"]:
            lines.append(f"- [{item['severity']}] {item['question']}")
        
        return "\n".join(lines)

#### 组件 3：Query 增强器

**功能**：将检查清单注入到 HeavySkill 的 query 中。

```python
class QueryEnhancer:
    """Query 增强器"""
    
    def __init__(self):
        self.classifier = DomainClassifier()
        self.checklist_manager = ChecklistManager()
    
    def enhance(self, original_query: str, file_content: str) -> str:
        """增强 query"""
        # 1. 识别领域
        domains = self.classifier.classify(file_content)
        
        # 2. 获取检查清单
        checklist = self.checklist_manager.get_checklist(domains)
        checklist_text = self.checklist_manager.format_checklist(checklist)
        
        # 3. 构建增强 query
        enhanced_query = f"""{original_query}

## 专项检查清单

请务必检查以下问题（这是必须回答的清单）：

{checklist_text}

## 输出要求

1. 对每个检查项，给出 ✅ 通过 / ❌ 不通过 / ⚠️ 部分通过 的评估
2. 对不通过的项，说明具体问题和位置
3. 给出总体结论（通过/附意见通过/不通过）
"""
        
        return enhanced_query
```

### 2.3 集成方式

#### 方式一：脚本集成（推荐）

```python
# heavyskill_enhanced_v2.py

from src.enhancer import QueryEnhancer, DomainClassifier, ChecklistManager

def enhance_query(query: str, file_path: str) -> str:
    """增强 HeavySkill query"""
    # 读取文件内容
    with open(file_path) as f:
        file_content = f.read()
    
    # 增强 query
    enhancer = QueryEnhancer()
    return enhancer.enhance(query, file_content)


def run_enhanced_heavyskill(query: str, file_path: str, **kwargs) -> Dict:
    """运行增强版 HeavySkill"""
    # 1. 增强 query
    enhanced_query = enhance_query(query, file_path)
    
    # 2. 运行 HeavySkill
    heavyskill_output = run_heavyskill(enhanced_query, file_path, **kwargs)
    
    # 3. 应用结论校验
    enhanced_output = enhance_output(heavyskill_output)
    
    return enhanced_output
```

#### 方式二：MCP Server 集成

```python
# mcp_server.py

from mcp import Server, Tool

server = Server("heavyskill-enhanced")

@server.tool("enhance_query")
async def enhance_query(query: str, file_path: str) -> dict:
    """增强 HeavySkill query"""
    enhancer = QueryEnhancer()
    enhanced = enhancer.enhance(query, file_path)
    return {"enhanced_query": enhanced}

@server.tool("run_enhanced_review")
async def run_enhanced_review(query: str, file_path: str) -> dict:
    """运行增强版审查"""
    # 完整流程
    enhanced_query = enhance_query(query, file_path)
    result = run_heavyskill(enhanced_query, file_path)
    return enhance_output(result)
```

## 八、总结

本方案通过 **检查清单注入** 的方式，针对 HeavySkill 的薄弱领域进行专项训练：

1. **领域识别器**：自动识别待审查方案的领域
2. **检查清单管理器**：管理各领域的专业检查清单
3. **Query 增强器**：将检查清单注入到 HeavySkill 的 query 中

**优势**：
- 立即可用，无需修改 HeavySkill 核心代码
- 成本低，只需创建检查清单和增强模块
- 效果可预期，检查清单直接引导模型关注关键问题

**预期效果**：
- 平均发现率从 71% 提升到 80%+
- 薄弱领域发现率提升 35-50%
