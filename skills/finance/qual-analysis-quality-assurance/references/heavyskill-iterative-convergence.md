## 收敛规律

- **前3轮**: 大幅提升(+6~+8分/轮)，解决架构级问题
- **第4轮**: 中等提升(+2分)，解决定义清晰化问题
- **第5轮**: 边际提升(+1.5分)，解决精细规则问题
- **收敛阈值**: 连续两轮增幅<3分时停止迭代

## 关键教训

1. **两位专家视角互补**: 投资专家关注"估值怎么算"，架构专家关注"模块怎么组织"
2. **P0问题必须先解决后再提交下一轮**
3. **子代理无法读取本地文件** — 必须将方案内容内联到query中
4. **max_concurrent_children=3** — 8轨迹需分3批执行(3+3+2)
5. **v3.1定位错误**: 被识别为"估值引擎"而非"质量保障体系"，必须补齐数据治理层和审计层

## Query模板

```bash
cd ~/.hermes/skills/heavyskill && python3 scripts/run_heavyskill.py \
  --query "你是独立第三方[投资分析/架构编程]专家，审查[方案名称]。
  
## vN→vN+1改进
[列出具体改进内容]

## 历史评分
v3.0: 72分, v3.1: 78分, ...

## 审查任务
评估是否达到[目标分数]。给出评分和剩余问题清单。" \
  --reason_k 8 --summary_k 4 --language cn
```
