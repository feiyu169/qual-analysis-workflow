# 买方定性分析模板 v2.0

> **版本**：2.0.0
> **日期**：2026-06-23
> **结构**：10+1 章（第0-10章）

---

## 模板说明

本模板定义了买方投资分析的完整结构，包含 10+1 章。每章包含：
- **CHAPTER_GOAL**：章节目标
- **CHAPTER_CONTRACT**：章节契约（must_answer + must_not_cover）
- **preferred_lens**：行业视角（可选）
- **ITEM_RULE**：条件项规则（可选）

### 使用方式

1. 首先执行类型推断，确定业务模型和约束条件
2. 根据推断结果应用行业视角和条件项
3. 逐章生成分析内容
4. 执行审计修复循环

---

## 第0章：投资要点概览

### CHAPTER_GOAL
用 300-500 字概括核心投资逻辑，让读者在 2 分钟内理解这笔投资的关键要素。

### CHAPTER_CONTRACT

**must_answer**:
- 一句话概括公司做什么
- 核心投资逻辑（为什么值得/不值得投资）
- 当前估值水平是否合理
- 最大的确定性和最大的不确定性

**must_not_cover**:
- 详细财务数据（留给后续章节）
- 行业详细分析（留给第2章）
- 详细风险列表（留给第9章）

### 内容结构

```
## 投资要点

**公司**：{company_name} ({ticker})
**一句话概括**：[公司做什么]

### 核心投资逻辑
[2-3 句话说明投资逻辑]

### 估值判断
[当前估值是否合理，关键假设]

### 关键不确定性
[最大的 1-2 个不确定性]
```

## 第1章：公司做的是什么生意

### CHAPTER_GOAL
深入理解公司的商业模式、产品/服务、客户群体、收入来源和价值链位置。

### CHAPTER_CONTRACT

**must_answer**:
- 公司提供什么产品或服务
- 客户是谁，客户为什么选择这家公司
- 收入来源和定价模式
- 价值链中的位置（上游/中游/下游）
- 核心竞争力是什么

**must_not_cover**:
- 行业宏观分析（留给第2章）
- 财务表现（留给第5章）
- 管理层评价（留给第8章）

### preferred_lens

根据业务模型自动应用行业视角：
- **platform**：平台经济视角（网络效应、双边市场）
- **saas**：SaaS 视角（ARR、NDR、LTV/CAC）
- **marketplace**：市场平台视角（take rate、GMV）
- **brand**：品牌消费视角（品牌力、渠道、复购）
- **tech_hardware**：科技硬件视角（产品周期、供应链）
- **pharma**：医药视角（管线、临床阶段、专利悬崖）
- **bank**：银行视角（净息差、资产质量、资本充足率）
- **insurance**：保险视角（承保利润、投资收益、准备金）
- **real_estate**：地产视角（土储、销售、负债率）

### ITEM_RULE

**条件项：多业务公司**
- **触发条件**：business_model 数组长度 > 2
- **必须包含**：分部收入占比、各业务协同关系
- **示例**：腾讯（社交+游戏+金融科技+云）

**条件项：全球化公司**
- **触发条件**：市场 = us 且包含 international 相关约束
- **必须包含**：各地区收入占比、本地化策略
- **示例**：苹果（全球供应链+全球销售）

### 内容结构

```
## 公司做的是什么生意

### 产品与服务
[详细描述产品/服务]

### 客户群体
[客户画像、客户粘性]

### 收入模式
[收入来源、定价策略]

### 价值链位置
[上游/中游/下游，与供应商和客户的关系]

### 核心竞争力
[护城河分析]
```

## 第2章：行业吸引力与公司位置

### CHAPTER_GOAL
分析所在行业的竞争格局、增长潜力、盈利能力和公司在行业中的相对位置。

### CHAPTER_CONTRACT

**must_answer**:
- 行业规模和增长率
- 行业竞争格局（集中度、主要玩家）
- 行业盈利能力（毛利率、ROE 行业对比）
- 公司的市场份额和竞争地位
- 行业驱动因素和未来趋势

**must_not_cover**:
- 公司具体财务数据（留给第5章）
- 公司管理层评价（留给第8章）
- 具体风险因素（留给第9章）

### preferred_lens

- **tech**：技术迭代视角（技术生命周期、颠覆风险）
- **consumer**：消费升级视角（品牌集中度、渠道变革）
- **financial**：金融监管视角（政策周期、利率环境）
- **healthcare**：医疗政策视角（集采、医保、审批）
- **industrial**：周期视角（产能周期、库存周期）
- **energy**：能源转型视角（碳中和、新能源替代）

### ITEM_RULE

**条件项：高集中度行业**
- **触发条件**：行业 CR3 > 60%
- **必须包含**：龙头溢价分析、行业壁垒
- **示例**：白酒（茅台+五粮液+泸州老窖）

**条件项：快速变化行业**
- **触发条件**：行业增长率 > 20%
- **必须包含**：技术路线风险、竞争格局演变
- **示例**：新能源、AI

### 内容结构

```
## 行业吸引力与公司位置

### 行业概况
[规模、增长率、生命周期阶段]

### 竞争格局
[主要玩家、市场份额、集中度]

### 行业盈利能力
[毛利率、ROE、资产周转率行业对比]

### 公司竞争地位
[市场份额、相对优势、差异化]

### 行业趋势
[驱动因素、未来3-5年展望]
```

## 第5章：经营表现与核心驱动

### CHAPTER_GOAL
分析公司的财务表现、盈利能力和增长驱动因素。

### CHAPTER_CONTRACT

**must_answer**:
- 收入增长趋势和驱动因素
- 盈利能力（毛利率、营业利润率、净利率）
- 现金流质量（经营现金流 vs 净利润）
- 资本回报率（ROE、ROIC）
- 增长可持续性分析

**must_not_cover**:
- 资产负债表详细分析（留给第6章）

### preferred_lens

- **growth**：成长股视角（收入增速、用户增长、TAM）
- **value**：价值股视角（自由现金流、分红、估值）
- **cyclical**：周期股视角（周期位置、库存、产能）
- **turnaround**：困境反转视角（问题诊断、改革措施）

**条件项：高增长公司**
- **触发条件**：收入增速 > 25%
- **必须包含**：增长驱动因素分解、增长可持续性评估

- **触发条件**：business_model 包含 cyclical
- **必须包含**：周期位置判断、历史周期对比
- **示例**：半导体、航运、有色金属

## 第6章：财务质量与资本配置

### CHAPTER_CONTRACT

### ITEM_RULE

**条件项：现金充裕公司**
- **触发条件**：cash > market_cap * 20%
- **必须包含**：现金用途分析、潜在回报路径
- **示例**：科技巨头（苹果、谷歌）
