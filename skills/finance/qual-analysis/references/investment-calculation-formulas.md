# 投资计算公式库 — 标准化参考

## 核心公式

### PB（市净率）
```
PB = 市值 / 归母净资产
⚠️ 必须使用归母净资产，不能用总权益
总权益 = 归母净资产 + 少数股东权益
```

### PE（市盈率）
```
PE = 市值 / 净利润
⚠️ 必须明确净利润口径：
- GAAP: 归母净利润（IFRS/CAS）
- adjusted: 经调整净利润（Non-IFRS，含股权激励等）
- core: 核心盈利（港股常用）
- deducted: 扣非净利润（A股特有）
```

### 市值
```
市值 = 股价 × 总股本（亿股）
⚠️ 注意单位：Wind可能返回万股，需÷10000转换为亿股
如总股本<1亿股，必须确认单位
```

### ROE（净资产收益率）
```
ROE = 归母净利润 / 归母净资产 × 100%
⚠️ 必须使用归母口径，不能用总权益
```

### 增长率
```
增速 = (当期 - 基期) / |基期| × 100%
⚠️ 基期为负时需特殊处理
⚠️ 必须标注基期是哪个期间
```

### CAGR（复合年增长率）
```
CAGR = (终止值/起始值)^(1/年数) - 1
```

### 自由现金流
```
FCF = 经营活动现金流 - 资本开支
```

### 现金流转化率
```
转化率 = 经营现金流 / 净利润 × 100%
正常范围：80%-120%
<50%: 盈利质量存疑
>200%: 可能有非现金收入
```

## 数据口径映射

### 净利润口径
| 口径 | 定义 | 适用市场 | Wind字段 |
|------|------|----------|----------|
| GAAP | 归母净利润 | A股/港股 | 年归属母公司股东的净利润 |
| adjusted | 经调整净利润 | 港股互联网 | 需从财报附注获取 |
| core | 核心盈利 | 港股地产 | 需从财报附注获取 |
| deducted | 扣非净利润 | A股 | 年扣除非经常性损益后的净利润 |

### 净资产口径
| 口径 | 定义 | 用途 |
|------|------|------|
| total | 总权益（含少数股东） | ❌ 不能用于PB计算 |
| parent | 归母净资产（不含少数股东） | ✅ PB计算必须使用 |

## 常见错误

1. **PB用总权益** → 低估5-15%
2. **PE口径不标注** → Non-IFRS vs GAAP差异10-30%
3. **股本单位错** → 万股vs亿股差10000倍
4. **增速基期错** → 用错基期导致增速偏差
6. **PE/PB混用币种** → 港股市值(港元)÷人民币净利润 = 虚高估值
7. **DCF终值占比过高** → 对永续增长率极其敏感，WACC每变1%目标价变20%

## 港股估值币种转换（Verified 2026-07-03）

港股公司市值以港元计价，财务数据以人民币计价，PE/PB计算必须统一币种。

**方法1：市值折算为人民币（推荐）**
```
市值(人民币) = 股价(HKD) × 总股本(亿股) × 汇率(0.92)
PE = 市值(人民币) / 净利润(人民币)
PB = 市值(人民币) / 归母净资产(人民币)
```

**方法2：财务数据折算为港元**
```
净利润(港元) = 净利润(人民币) / 汇率(0.92)
PE = 市值(港元) / 净利润(港元)
```

**美图实测**:
- 错误：59.56亿HKD / 5.83亿RMB = 10.2x ❌
- 正确：54.80亿RMB / 5.83亿RMB = 9.40x ✅

**汇率假设**: 报告必须标注使用的汇率（如1 HKD = 0.92 RMB）

## 加密货币持仓对利润分析的干扰（Verified 2026-07-03）

当公司持有加密货币时，净利润可能包含大量非经常性损益。

**调查方法**:
1. 对比营业利润vs净利润趋势（如营业利润增67%但净利润降27%）
2. 搜索公司加密货币持仓历史（关键词：比特币、以太坊、加密货币）
3. 查阅资产负债表"权益性投资"科目变化
4. 查阅利润表"投资收益"/"公允价值变动"科目

**美图实测**:
- 2021年购入BTC/ETH约1亿美元
- 2024年12月清仓全部，获利5.71亿元
- FY2024净利润包含加密货币出售收益约3亿
- FY2025净利润反映真实经营状况

**规则**: 净利润与营业利润趋势背离时，必须查明非经常性损益来源。
