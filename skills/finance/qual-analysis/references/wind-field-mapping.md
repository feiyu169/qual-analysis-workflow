## 关键发现

1. **Wind 不提供**: 有息负债、货币资金(单独)、总股本、EPS、每股净资产、增长率、Beta
2. **Wind valuation 不返回 PE/PB**: 只返回价格数据(开盘/收盘/成交量)
3. **3年数组**: 数值字段返回3年数据数组，需取最新一年(最后一个元素)
4. **港股 vs A股**: 港股字段名带"过去3年每年"前缀，A股带"年"前缀
5. **单位**: 大部分为亿元，但 EBITDA 单位可能是元(需检查)

## 统一映射模块

字段映射和工具函数已统一到 `data_context.py`:
```python
from finance.data_context import WIND_FIELD_MAPPING, safe_get, has_field, latest_value
```

- `safe_get(data, "营业收入")` → 自动映射到 `data["年营业总收入"]`
- `latest_value(data, "经营活动现金流")` → 自动映射并取3年数组最新值
- `has_field(data, "营业收入")` → 检查直接名或映射名是否存在
