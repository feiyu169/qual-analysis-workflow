## 一、内核验证检查清单（无LLM，<10ms）

### 1.1 关键词硬性门槛

| 检查项 | 必须包含的关键词 | 最少命中 | 权重 |
|--------|------------------|----------|------|
| 财务分析 | 营收+净利润+毛利率+ROE+现金流 | 5/5 | 15% |
| 增长分析 | 同比/环比+CAGR+驱动因素 | 3/3 | 10% |
| 行业分析 | 市场规模+竞争格局+集中度 | 3/3 | 10% |
| 估值分析 | PE/PB/PS/EV/EBITDA+DCF/安全边际 | 2/2 | 15% |
| 风险分析 | 风险+下行/尾部+应对/缓释 | 3/3 | 10% |
| 投资建议 | 买入/持有/卖出+目标价+预期收益 | 3/3 | 10% |
| 数据引用 | 匹配 `\d+(\.\d+)?%` 或 `\d+(\.\d+)?亿` | ≥20个 | 15% |
| 逻辑连接词 | 因此/所以/综上/基于以上/由此可知 | ≥5处 | 5% |
| 时间序列 | 2022/2023/2024/2025（≥2个年份） | ≥2个 | 5% |
| 数据来源 | 年报/季报/Wind/Bloomberg/公告 | ≥2处 | 5% |

### 1.2 结构完整性检查

| 检查项 | 检查方式 | 通过标准 | 权重 |
|--------|----------|----------|------|
| 维度完整性 | 检查章节标题: 公司/行业/估值/风险/建议 | ≥5/6命中 | 20% |
| 横向对比 | 是否出现≥2个公司名/代码 | ≥2家 | 10% |
| 纵向趋势 | 是否出现≥3个时间点数据 | ≥3个 | 10% |
| 定量vs定性 | 数字出现次数 vs 文字比例 | ≥每100字1个数据点 | 15% |
| 正反论证 | 正面词(优势/利好)+负面词(风险/挑战) | 各≥3处 | 10% |
| 结论支撑 | 投资建议前是否有≥3个论据 | ≥3个 | 15% |
| 假设披露 | "假设/前提/基于/条件"等词 | ≥3处 | 10% |
| 不确定性 | "可能/或/概率/情景/区间" | ≥5处 | 10% |

| 检查项 | 检查方式 | 通过标准 | 权重 |

## 三、评分器计算公式

### 3.1 L3评分公式

```python
def calculate_l3_score(report):
    # 数据点得分（0-30分）
    data_points = count_data_points(report)  # 正则提取数字
    data_score = min(30, data_points * 1.5)
    
    # 逻辑链得分（0-40分）
    logic_score = 0
    if has_causal_chain(report, min_count=2): logic_score += 15
    if has_data_conclusion_consistency(report): logic_score += 15
    if has_valuation_consistency(report): logic_score += 10
    
    # 维度覆盖得分（0-30分）
    dimensions = ['公司基本面', '行业分析', '估值分析', '风险分析', '投资建议']
    coverage = sum(1 for d in dimensions if d in report)
    coverage_score = coverage * 6
    
    return data_score + logic_score + coverage_score  # ≥70通过
```

### 3.2 L4评分公式

```python
def calculate_l4_score(report):
    # 数据密度（0-20分）
    data_density = count_data_points(report) / len(report) * 10000
    density_score = min(20, data_density * 2)
    
    # 方法论深度（0-30分）
    method_score = 0
    if has_dupont_analysis(report): method_score += 10
    if has_sensitivity_analysis(report): method_score += 10
    if has_scenario_analysis(report): method_score += 10
    
    # 逻辑链层级（0-30分）
    chain_depth = count_logic_chain_depth(report)  # 1层=10, 2层=20, 3层=30
    chain_score = min(30, chain_depth * 10)
    
    # 情景覆盖（0-20分）
    scenario_score = 0
    if has_bull_case(report): scenario_score += 7
    if has_base_case(report): scenario_score += 7
    if has_bear_case(report): scenario_score += 6
    
    return density_score + method_score + chain_score + scenario_score  # ≥80通过
```

## 四、HeavySkill审查要点

当使用HeavySkill审查投资分析报告时，注入以下检查清单：

```
## 审查维度
1. **深度标准符合度** — 是否达到L3/L4的具体指标要求？
2. **数据准确性** — 关键财务数据是否与Wind一致？
3. **逻辑完整性** — 因果链、估值一致性、风险-仓位匹配
4. **行业视角应用** — preferred_lens是否真正体现在分析中？
5. **must_answer覆盖** — 每个must_answer项是否被实质性回答？
```
