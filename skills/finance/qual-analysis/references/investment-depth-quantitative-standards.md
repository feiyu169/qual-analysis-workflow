# 投资分析深度量化标准 v1.0

> 生成时间: 2026-07-01

## 一、深度级别定义

| 级别 | 定位 | 总字数 | 总数据点 | 通过阈值 | 检验公式 |
|------|------|--------|----------|----------|----------|
| L3 | 标准深度 | ≥3000字 | ≥20个 | 70分 | 数据点×0.3 + 逻辑链×0.4 + 维度覆盖×0.3 |
| L4 | 专业深度 | ≥6000字 | ≥40个 | 80分 | 数据密度×0.2 + 方法论深度×0.3 + 逻辑链层级×0.3 + 情景覆盖×0.2 |
| L5 | 机构级 | ≥10000字 | ≥60个 | 90分 | 预测精度×0.25 + 风险量化×0.25 + 情景完备性×0.25 + 另类验证×0.25 |

## 二、L3 标准深度分析

| 分析维度 | 最低数量 | 数据支撑 | 逻辑链要求 |
|----------|----------|----------|------------|
| 公司基本面 | ≥3年数据对比 | 5指标×3年=15数据点 | 增长趋势→驱动因素→可持续性 |
| 行业分析 | ≥2个竞争对手 | 行业规模/增速/集中度≥3指标 | 行业空间→竞争格局→公司定位 |
| 估值分析 | ≥2种方法 | PE/PB/PS≥2种+历史分位数 | 绝对估值→相对估值→安全边际 |
| 风险分析 | ≥3个风险 | 每个量化(概率×损失) | 识别→量化→应对 |
| 投资建议 | 明确评级 | 目标价+当前价+预期收益率 | 逻辑→结论→催化剂/止损 |

## 三、L4 专业深度分析

| 分析维度 | 最低数量 | 数据支撑 | 逻辑链要求 |
|----------|----------|----------|------------|
| 商业模式拆解 | ≥3层价值链 | 分业务≥5数据点 | 价值创造→价值传递→价值捕获 |
| 财务深度 | ≥5年+季度 | 三表联动≥25数据点 | 杜邦分析或现金流质量分析 |
| 行业深度 | ≥5个竞争对手 | CR5/CR10/HHI+波特五力 | 产业链→价值链→利润池 |
| 管理层评估 | ≥3位高管 | 薪酬/持股/业绩≥5数据点 | 能力→动机→约束 |
| 估值矩阵 | ≥3种方法+三情景 | DCF/可比/可比交易 | 方法论选择→参数假设→敏感性 |
| 催化剂/风险 | ≥5+≥5 | 量化时间窗口+影响幅度 | 概率-影响二维矩阵 |
| 交易策略 | 仓位+建仓节奏 | 波动率/回撤/VaR≥3指标 | 入场→持仓→退出 |

## 四、L5 机构级深度分析（补充）

| 分析维度 | 最低数量 | 数据支撑 | 逻辑链要求 |
|----------|----------|----------|------------|
| 战略全景 | ≥5年历史+3年预测 | BCG/GE矩阵各象限≥2指标 | 资源→能力→壁垒→护城河 |
| 财务建模 | ≥3张完整预测表 | ≥50假设参数+来源标注 | 驱动因素→假设→敏感性→蒙特卡洛 |
| 行业生态 | ≥10个参与者 | 产业链各环节≥15数据点 | 产业地图→利益分配→演化路径 |
| ESG/治理 | ≥5个ESG维度 | 碳排放/员工流失/董事会独立性≥8数据点 | ESG风险→财务影响传导 |
| 多维度估值 | ≥4种方法+概率加权 | DCF/DDM/SOTP/实物期权 | 估值区间→概率分布→期望值→置信区间 |
| 宏观环境 | ≥3个宏观变量 | GDP/利率/汇率/通胀+相关性 | 宏观假设→行业传导→公司影响 |
| 另类数据 | ≥3个另类源 | 卫星/社媒/招聘等非传统指标 | 另类数据→传统数据→交叉验证 |

## 五、同义词容错规则

内核验证中的关键词匹配需支持同义词：

| 标准词 | 同义词/变体 |
|--------|------------|
| 营收 | 营业收入、收入、总营收、营业总收入 |
| 净利润 | 归母净利润、净利、归属母公司净利润 |
| 毛利率 | 毛利、综合毛利率 |
| ROE | 净资产收益率、ROE(摊薄)、ROE(加权) |
| 同比 | YoY、year-over-year |
| CAGR | 复合增长率、复合年均增长率 |
| PE | 市盈率、P/E |
| PB | 市净率、P/B |
