## 核心架构（v6.0）

### 审计主管道
```
QualityContext → DataCollector → CausalInference → ScoreEngine → DegradationPolicy → Output
```

### 推理链：单链3阶段
1. 数据预处理：证据抽取、数据校验
2. 因果-情景建模：因果建模+情景推演+对抗校验（反面论证子模块）
3. 结论合成：综合结果、计算置信度

### 评分器：5维度+证伪
| 维度 | 权重 | 子维度 |
|------|------|--------|
| D1 数据完整性 | 20% | 源覆盖40%+时效30%+交叉验证30% |
| D2 逻辑一致性 | 25% | 因果链40%+数据距离30%+估值一致性30% |
| D3 分析深度 | 25% | 维度覆盖30%+横纵对比30%+正反论证40% |
| D4 结论可靠性 | 20% | 投资建议40%+催化剂30%+风险矩阵30% |
| D5 可操作性 | 10% | 目标价40%+仓位30%+止损30% |
| 证伪指标 | 独立 | 反方论点40%+证伪可操作性40%+监控完整性20% |

### 强制降级规则
- 证伪<5分 → 强制D级
- 证伪<10分 → 降级到C级（仅S/A/B）

### 因果建模方法
混合方法：模板匹配+Granger检验+敏感性分析
