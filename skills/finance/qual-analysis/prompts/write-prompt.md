## 写作指南

### 结构要求

1. **引言**：1-2 句话概括本章核心观点，吸引读者
2. **小节**：每个小节聚焦一个子主题，通常 3-5 个小节
3. **小结**：总结本章核心发现，与投资逻辑关联

### 数据使用

1. **引用数据**：关键数据要注明来源（如"根据2024年报"）
2. **对比分析**：尽量与历史、同行、行业进行对比
3. **数据可视化**：用表格呈现关键数据对比

### 观点表达

1. **明确立场**：不要模棱两可
2. **说明依据**：观点必须有数据或逻辑支撑
3. **承认不确定性**：不确定的地方要明确说明

### 语言风格

1. **专业但不晦涩**：使用专业术语但要解释
2. **简洁有力**：避免冗长的句子
3. **逻辑清晰**：使用连接词确保逻辑流畅

## 事实核查红线（必须遵守）

1. **投资/并购声明**：只能写财报原文中明确提到的投资活动。如果原文未提及投资京东、拼多多等，绝不能编造。
2. **管理层职务**：必须以财报原文中的职务描述为准。如果财报发布时管理层已变更，以财报为准。
3. **盈利/亏损状态**：以财报中的净利润数据为准，不得与财报数据矛盾。
4. **分红/回购记录**：必须引用财报原文中的具体金额和日期，不得编造。
5. **交叉一致性**：ch06(财务质量)中提到的分红/回购记录必须与ch07(股东回报)完全一致。

## 数据精确性要求

1. 所有财务数字必须使用财报原文中的精确值，不得使用"约XX%"或"大约XX亿"
2. 引用格式: "2023年营业收入为人民币1,135.7亿元 [来源: 2023年年报 第15页]"
3. 如果财报原文中有表格数据，优先使用表格中的精确数字
4. 增长率必须给出基数和结果: "营业收入从867.2亿增长至1,135.7亿，同比增长30.9%"

4. **遵循契约**：严格遵守 must_answer 和 must_not_cover 的要求
