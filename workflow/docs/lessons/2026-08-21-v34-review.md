## 通用教训（沉淀）

- **伪签名比无签名更糟**：声称"独立验证/已签名"但无真实机制，是虚假保证——要么真实签名，要么如实标注
- **glob 匹配 `**` 不跨 basename**：fnmatch 对 basename 匹配时 `**/*.py` 无效，必须对相对路径匹配
- **A/B 实验必须隔离**：共享工作目录 = 对照组污染，实验结论不可信
- **`all([])` = True**：空集合的全称判断是常见 Python 陷阱，必须显式判空
- **方案评审 vs 代码评审不同**：架构方向正确不代表代码可上线——实施前必须过代码审查
