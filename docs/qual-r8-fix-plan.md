## 五、根因反思（为何 R6 估值层模板残留）

R6 的估值专节来自 `quality_enhancer` 或 `_generate_chapter` 的 LLM 输出——**prompt 未强制"估值数字必须用本报告 Wind 锚点"**。
翻转阈值 1427.8 与美团/小鹏同款，说明 **LLM 复用了训练数据里的模板数值**（deepseek-v4-flash 在长上下文下
把别的报告的估值表"记忆"进来）。修复：估值章节 prompt 注入 Wind 锚点 + "禁止使用锚点外任何数值"铁律，
并加**数值量级校验**（估值营收必须与报告收入同量级，差>5倍即 P0）。
